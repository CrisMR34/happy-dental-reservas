# Happy Dental Reservas

Prototipo web independiente de reservas para Happy Dental Santiago.

## Funciones

- Reserva de odontología y estética facial.
- Identificación por RUT y recuperación de ficha existente.
- Registro de nombre, WhatsApp y correo.
- Agenda administrativa.
- Gestión de pacientes, profesionales, servicios y horarios.
- Historial de atenciones.
- Confirmación de WhatsApp simulada.
- Ubicación: Av. Francisco Bilbao 2419, Providencia, Región Metropolitana.
- Diseño responsive pensado principalmente para celulares.

## Ejecución

El proyecto es estático. El archivo principal es `index.html` y puede publicarse directamente con Cloudflare Pages, GitHub Pages u otro hosting estático.
